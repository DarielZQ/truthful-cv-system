# Requirements

## Functional

1. Store evidence, claims, roles, education, credentials, skills, projects, metrics, and redlines with stable IDs.
2. Preserve source, evidence status, attribution, confidentiality, and confirmation state.
3. Import a saved job description and extract must-haves, preferences, responsibilities, seniority, language, and location constraints.
4. Produce a transparent requirement-to-claim fit matrix.
5. Stop or flag weak fits and hard filters.
6. Select and order only approved claims for a role.
7. Produce a content manifest and RenderCV YAML.
8. Automatically verify PDF readability, page count, literal redlines, and normalized manifest-text coverage; visually review ordering, contacts, headings, links, and layout before delivery.
9. Maintain application versions and a duplicate-safe job tracker.
10. Optionally draft evidence-based cover letters and screening answers.

## Non-functional

- Private-first and Windows-compatible.
- Reproducible pinned dependencies.
- Deterministic validators around model-assisted analysis.
- Human approval before sending or making legal/personal declarations.
- Plain YAML/JSON/Markdown data that outlives any model or renderer.
- Automated tests for every production behavior.
